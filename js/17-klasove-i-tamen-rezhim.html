2. Обяснение

classList: add, remove, toggle, contains

Добрата практика е видът да е в CSS, а JavaScript само да слага и маха класове.

element.classList.add("ime") добавя клас. remove го маха. toggle го слага или маха според това дали го има. contains връща истина или лъжа.

document.body.classList.toggle("tamen");
if (document.body.classList.contains("tamen")) {
  buton.textContent = "Светъл режим";
}

Условието if изпълнява код само ако нещо е вярно. Частта else се изпълнява, ако не е вярно.

Така можете да правите менюта, които се отварят и затварят, раздели, които се показват при натискане, и много други неща. В сайта Приказки от упражненията бутонът за тема работи точно така.

3. Предизвикателство

Скрит отговор

Направете гатанка, чийто отговор се показва и скрива с бутон. Изпълнявайте стъпките една по една. След всяка стъпка натиснете Провери.

  1. В CSS направете клас skrit, който скрива елемента с display: none.

    Подсказка: .skrit { display: none; }.

  2. Дайте класа skrit на отговора, така че в началото да е скрит.

    Подсказка: <p id="otgovor" class="skrit">.

  3. При натискане на бутона превключвайте класа skrit на отговора с toggle.

    Подсказка: намерете двата елемента и в addEventListener напишете otgovor.classList.toggle("skrit");.

  4. Сменяйте и текста на бутона: Покажи отговора или Скрий отговора.

    Подсказка: използвайте if и classList.contains("skrit").
