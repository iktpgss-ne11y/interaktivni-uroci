2. Обяснение

Намери, слушай, промени

Почти всеки скрипт в страница прави три неща. Намира елемент. Слуша за събитие. Променя нещо.

Намери

document.getElementById("ime") връща елемента с това id. Запомняме го в променлива с const.

Слушай

element.addEventListener("click", function () { ... }) казва: когато натиснат елемента, изпълни кода във фигурните скоби.

Промени

textContent е текстът в елемента. style дава достъп до CSS свойствата. В JavaScript тирето отпада и следващата буква става главна: background-color става backgroundColor.

const buton = document.getElementById("buton");
buton.addEventListener("click", function () {
  buton.textContent = "Готово!";
});

Ако нещо не работи, натиснете F12 и вижте раздела Console. Там браузърът пише грешките в червено.

Внимавайте с главните и малките букви. getElementById не е същото като getelementbyid.

3. Предизвикателство

Брояч на гласове

Направете бутон, който брои колко пъти е натиснат. Изпълнявайте стъпките една по една. След всяка стъпка натиснете Провери.

  1. В тага script намерете двата елемента по id и ги запазете в променливи broi и glasuvai.

    Подсказка: const broi = document.getElementById("broi");.

  2. Създайте променлива glasove с начална стойност нула. Тя ще се променя, затова използвайте let.

    Подсказка: let glasove = 0;.

  3. Когато бутонът бъде натиснат, увеличете glasove с едно и покажете новата стойност в broi.

    Подсказка: в addEventListener: glasove = glasove + 1; и broi.textContent = glasove;.

  4. Когато гласовете станат десет или повече, оцветете числото в зелено.

    Подсказка: if (glasove >= 10) { broi.style.color = "green"; }.
