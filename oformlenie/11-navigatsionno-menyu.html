3. Обяснение

От списък до меню

Менюто е списък с връзки в таг nav. Така то е разбираемо и без CSS, и за програмите за четене.

Стъпките

Първо махнете точките и отстоянията на списъка: list-style: none, margin: 0 и padding: 0.

После подредете редовете хоризонтално с display: flex на списъка ul.

След това оформете връзките: цвят, без подчертаване с text-decoration: none и вътрешно отстояние. Дайте им display: block, за да е натискаема цялата площ.

Накрая добавете :hover за ефект при посочване.

nav ul { list-style: none; margin: 0; padding: 0; display: flex; }
nav a { display: block; padding: 14px 20px; color: white; text-decoration: none; }
nav a:hover { background-color: #ffca28; }

Селекторът nav a означава всички връзки, които са вътре в nav. Така стилът не засяга другите връзки на страницата.

Добре е текущата страница да е отбелязана. Дайте на нейната връзка клас, например aktivna, и ѝ сложете различен цвят.

4. Предизвикателство

Меню за сайта на класа

Превърнете списъка в истинско хоризонтално меню. Изпълнявайте стъпките една по една. След всяка стъпка натиснете Провери.

  1. Дайте тъмен фон на nav.

    Подсказка: nav { background-color: #1a237e; }.

  2. Махнете точките и отстоянията на списъка.

    Подсказка: в правило nav ul: list-style: none; margin: 0; padding: 0;.

  3. Подредете връзките в хоризонтален ред.

    Подсказка: display: flex; в правилото за nav ul.

  4. Оформете връзките: бял текст, без подчертаване, вътрешно отстояние и display: block.

    Подсказка: правило nav a с color, text-decoration, padding и display.

  5. Добавете различен фон при посочване с мишката.

    Подсказка: nav a:hover { background-color: ... }.

  6. Отбележете активната страница: връзката с клас aktivna да има свой фон.

    Подсказка: nav a.aktivna или само .aktivna.
