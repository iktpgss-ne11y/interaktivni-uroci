2. Обяснение

Контейнер и деца

Flexbox работи с контейнер и деца. Свойствата се пишат на контейнера, а подреждат децата му.

display: flex включва подреждането. Децата застават в ред.

gap задава разстоянието между децата.

flex-wrap: wrap позволява децата да минат на нов ред, когато няма място.

justify-content разпределя децата по главната посока. Стойности: flex-start в началото, center в средата, space-between с равно място между тях.

align-items ги подравнява по другата посока, например center по вертикала.

flex-direction сменя посоката: row е ред, column е колона.

.karti {
  display: flex;
  gap: 12px;
  flex-wrap: wrap;
  justify-content: center;
}

Детето може да има flex: 1. Тогава то заема цялото свободно място. Ако три деца имат flex: 1, те делят мястото по равно.

3. Предизвикателство

Ценоразпис на фитнес

Подредете трите карти с цени една до друга. Изпълнявайте стъпките една по една. След всяка стъпка натиснете Провери.

  1. Подредете картите в ред с display: flex на контейнера .planove.

    Подсказка: свойството е на контейнера, не на картите: .planove { display: flex; }.

  2. Сложете шестнадесет пиксела разстояние между картите.

    Подсказка: gap: 16px;.

  3. Направете трите карти еднакво широки, така че да заемат цялата ширина.

    Подсказка: дайте на .plan flex: 1;.

  4. Подравнете картите по средата по вертикала с align-items.

    Подсказка: align-items: center; на контейнера.
