CSS основи.

Цветове, селектори, текст и блоков модел. Отговорете вярно пет пъти поред.

Въпрос 1. Кое свойство сменя цвета на текста?
Отговор: колър.
Цветът на текста е color.

Въпрос 2. Кой селектор хваща всички елементи с клас инфо?
Отговор: .info.
Класът се пише с точка.

Въпрос 3. Кой селектор хваща елемента с ай ди меню?
Отговор: #menu.
id се пише с диез.

Въпрос 4. Кое свойство задава размера на шрифта? Напишете само името.
Отговор: фонт сайз.
Размерът е font-size.

Въпрос 5. Кое свойство задава вътрешното отстояние? Напишете само името.
Отговор: падинг.
Вътрешното отстояние е padding.

Въпрос 6. Елемент има правило по клас, по което е зелен, и правило по id, по което е син. Какъв е?
Отговор: Син..
Правилото по id е по-точно и печели.

Въпрос 7. Какво липсва в пи, колър ред?
Отговор: Двоеточие..
Между свойството и стойността се пише двоеточие.

Въпрос 8. Кой вид рамка е пунктирана?
Отговор: дашт.
dashed е пунктир, dotted е точки, solid е плътна линия.

Въпрос 9. Подредете слоевете на кутията отвътре навън.
Отговор: съдържание, padding, border, margin.
Отвътре навън: съдържание, вътрешно отстояние, рамка, външно отстояние.

Въпрос 10. Направете всички заглавия h2 сини.
h2 { color: blue; }

Въпрос 11. Поправете CSS кода, така че абзацът с клас note да има жълт фон.
Липсваше точката пред името на класа.

Въпрос 12. Дайте на кутията вътрешно отстояние 10px и плътна черна рамка 1px.
padding: 10px; border: 1px solid black;

Въпрос 13. Центрирайте текста на заглавието h1.
h1 { text-align: center; }
