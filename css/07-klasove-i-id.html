Класове и id: стил само за някои елементи

Ще научите как да дадете различен стил на елементи от един и същи вид.

Време: около 30 минути.

1. Видеообяснение

Различни абзаци

Видеото има глас и субтитри. Под него е същото обяснение, но интерактивно: можете да спрете и да промените кода сами.

Натиснете Пусни. Кодът ще се пише сам, а гласът ще обяснява. Можете да спрете по всяко време, да промените кода и да видите какво става.

2. Обяснение

Три вида селектори

Селектор по таг

Пише се само името на тага, например p. Важи за всички такива елементи.

Селектор по клас

Пише се точка и името на класа, например .vazhno. Важи за всички елементи с class="vazhno". Много елементи могат да имат един клас, а един елемент може да има няколко класа.

Селектор по id

Пише се диез и името, например #zaglavie. Важи за единствения елемент с това id.

p { color: #333; }
.vazhno { color: crimson; }
#zaglavie { background-color: gold; }

Когато няколко правила си противоречат, печели по-точното. Правилото с id е по-силно от правилото с клас, а то е по-силно от правилото с таг. Затова абзацът с клас vazhno е червен, въпреки правилото за p.

Използвайте класове за стил. Оставете id за връзки към място в страницата и за JavaScript.

3. Предизвикателство

Меню в столовата

Оцветете менюто така, че вегетарианските ястия и ястието на деня да се виждат веднага. Изпълнявайте стъпките една по една. След всяка стъпка натиснете Провери.

  1. Дайте клас vegetariansko на Таратор и на Баница.

    Подсказка: <li class="vegetariansko">Таратор</li>.

  2. Напишете CSS правило за клас vegetariansko, което прави текста зелен.

    Подсказка: селекторът за клас започва с точка: .vegetariansko { color: green; }.

  3. Дайте на Мусака id="na-denya" и с CSS му дайте жълт фон.

    Подсказка: селекторът за id започва с диез: #na-denya.

  4. Създайте клас novo, който прави текста удебелен със font-weight: bold. Дайте го на Баница като втори клас.

    Подсказка: двата класа се пишат с интервал: class="vegetariansko novo".
